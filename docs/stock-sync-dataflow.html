Two devices sync after working offline

Each phone saves its operation locally first. When both reconnect, the backend serializes the writes into one group log, then each phone pulls the ordered log and advances its cursor.

function recordOffline(op):
  transaction:
    request = { opId: uuid(), deviceId, deviceSeq, baseSeq: lastAppliedSeq, op }
    outbox.append(request); deviceSeq += 1
    applyOptimistically(op)
 
async function sync():
  await pullUntilCaughtUp()
  for request in outbox.sortedBy(deviceSeq):
    response = await POST("/api/stock/ops", request)
    if response.ok: remove request from outbox
    if timeout: retry same opId, deviceSeq, and body
  await pullUntilCaughtUp()
 
async function pullUntilCaughtUp():
  page = GET("/api/stock/ops?after=" + lastAppliedSeq)
  transaction:
    for op in page.ops ordered by seq: apply(op)
    persist inventory and page.nextAfter together
  if page.hasMore: request next page
            
          

        

        

          
Backend
VALIDATE + SEQUENCE + LOG

          

            
POST /api/stock/ops:
  authenticate; authorize group membership
  validate schema and operation fields
  if opId already exists: return saved result + latestSeq
  transaction; lock group sequence counter
  require deviceSeq == lastDeviceSeq + 1
  require baseSeq <= current group sequence
  lock affected stock positions
  if count.expected differs: rollback; return 409
  apply event to current onHand
  assign seq; persist op, snapshot, and deviceSeq
  commit transaction
  return { seq, latestSeq, onHand }
 
GET /api/stock/ops?after=n:
  authenticate; authorize group membership
  latestSeq = current group sequence
  read ordered ops where n < seq <= latestSeq, limit 500
  return ops, nextAfter, hasMore, latestSeq
